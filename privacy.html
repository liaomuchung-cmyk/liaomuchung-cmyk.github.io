適用範圍 Scope

「牧群小秘書」是廖牧群個人使用的助理程式，唯一使用者為其本人。The only user of this application is its owner.

存取的資料 Data accessed

  • Google Calendar：讀取與新增本人行程。Read and create the owner's calendar events.
  • Gmail（唯讀 read-only）：讀取本人信件以產生每日摘要；不寄信、不刪信、不修改信件。Read the owner's messages to produce a daily digest; never sends, deletes, or modifies mail.

資料使用與分享 Use and sharing

資料僅供本人個人用途，不出售、不分享給任何第三方，也不用於廣告。Data is used only for the owner's personal purposes and is never sold, shared with third parties, or used for advertising.

本應用對 Google 使用者資料的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

撤銷授權 Revoking access

可隨時於 https://myaccount.google.com/permissions 撤銷授權。Access can be revoked at any time at https://myaccount.google.com/permissions.
